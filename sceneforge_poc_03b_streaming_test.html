Sebelum mulai

Saat tombol ditekan, Chrome akan meminta lokasi dan nama file MP4. Pilih folder yang mudah ditemukan. Biarkan Chrome tetap terbuka dan halaman tetap di depan sampai selesai. Jika kamu membatalkan pemilih file, tes tidak dimulai.

Yang diuji

StreamTarget menulis potongan output berdasarkan posisi byte dan menerapkan backpressure. Frame diproses satu per satu, audio memakai buffer 1 detik, dan MP4 tidak ditampung seluruhnya dalam BufferTarget. Ini pengujian streaming output, bukan pengukuran RAM perangkat secara langsung.
